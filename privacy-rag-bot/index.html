🔒 Privacy-Aware RAG Bot

MLH Global Hack Week: Builders Week — The Privacy-Aware RAG Bot (Auth0 FGA). An internal HR / Legal knowledge assistant. It retrieves answers from a document database — but every candidate document passes an Auth0 FGA authorization check first. A manager can read salary documents; a general employee cannot, even though the document is in the RAG index.

Honest scope: static, no-backend demo. Retrieval is real keyword scoring over the in-page document index. The Auth0 FGA check is a small in-page engine implementing the authorization model shown below (no live Auth0 FGA store is called); it models exactly the rule from the challenge — user:alice can view document:budget_Q4, user:bob cannot view document:salary_bands.

Auth0 FGA authorization model (as implemented in this demo)

model
  schema 1.1
type user
type document
  relations
    define viewer: [user] or viewer from department
type department
  relations
    define member: [user]

# Tuples (who can view what):
# document:handbook   #viewer @user:*        (everyone)
# document:pto_policy #viewer @user:*        (everyone)
# document:budget_Q4  #viewer @user:alice    (HR manager)
# document:salary_bands #viewer @user:alice  (HR manager only)
# document:legal_nda  #viewer @user:carol    (Legal counsel)
