🛡️ Veto Agent

MLH Global Hack Week: Builders Week — The Veto Agent (Token Vault & Asynchronous Authorization / CIBA). An AI agent connected to a third-party service (GitHub). Low-risk actions run at once. High-impact actions pause and ask for approval out of band — in the Approval Inbox below, simulating a push notification / email — and stay halted until you Approve or Veto them.

Honest scope: this is a static demo. The Token Vault is simulated in memory only (a token you type is held in a JS variable, never saved to localStorage, never shown in full, and is cleared on Revoke / reload). High-impact actions are simulated — nothing is ever really deleted or scheduled. The GitHub fetch below is real: it calls the public GitHub API.
